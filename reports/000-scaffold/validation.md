# Подготовка пустого каркаса

Дата: 15.10.2026. Основание: отдельное подтверждение пользователя на подготовку каркаса после завершения интервью.

## Изменения

- HTML-страница с названием проекта, названием банка и сообщением о подготовке.
- Минимальные CSS и JavaScript; без каталога, фильтров, реальных и вымышленных проектов.
- Vite для запуска и сборки, Vitest для будущих тестов логики, Playwright для браузерных проверок.
- Команды dev, build, preview, test:unit (без watch), test:e2e.
- Зафиксированы точные версии и pnpm-lock.yaml.
- Настроено исключение старого прототипа из тестов (явная область tests/unit) и служебных папок из Git.
- README обновлён фактическими командами.

## Уже выполненные проверки

- Node.js v24.19.0.
- Установка: pnpm add -D vite vitest @playwright/test --save-exact. Успешно: Vite 8.3.4, Vitest 5.0.4, Playwright 1.64.0.
- node node_modules/vite/bin/vite.js build: exit code 0; 5 модулей, статические файлы в dist/.
- node node_modules/vitest/vitest.mjs run: exit code 1; No test files found. Бизнес-тесты отсутствуют, успех не заявляется.
- git diff --check: exit code 0 (информационное предупреждение Git об окончаниях строк).

Браузерная проверка: node node_modules/@playwright/test/cli.js test — exit code 0, 1 passed (9.9s). Проверены загрузка, заголовок, сообщение каркаса, перезагрузка и отсутствие pageerror. Скриншот scaffold.png осмотрен: наложений и обрезанного текста не выявлено. Используется установленный полный Chromium через channel chromium; скачивание дополнительного headless-shell остановлено как ненужное. Команда повторной установки: pnpm exec playwright install chromium --no-shell. Первый запуск в песочнице выполнил тест, но завис при завершении; прерван. Повторный запуск с разрешением вне песочницы завершился успешно.
