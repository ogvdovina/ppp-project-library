# Библиотека проектов ГЧП — подготовка по курсу

Источник порядка работы: PDF «Вайбкодинг · Занятие 2». Навыки и роли скопированы из архива «Мини-сад» без изменений; AGENTS.md адаптирован под предмет проекта.

## Подготовленные файлы

- AGENTS.md — правила проекта.
- GOAL.md — цель и состав первой версии, подтверждённые после интервью 15.10.2026.
- STATUS.md — фактическое состояние.
- plans/ — согласованные планы.
- reports/ — отчёты разработки и проверки.
- .agents/skills/interview-me/ — интервью до планирования.
- .agents/skills/implement/ — последовательная работа четырёх ролей по подтверждённому плану.
- .codex/agents/ — demo-implementer, demo-test-writer, demo-test-runner, demo-auditor.

## Последовательность

1. Подготовить рабочую папку и конфигурации.
2. Провести interview-me: один вопрос за раз, затем подтвердить формулировку замысла.
3. Заполнить GOAL.md по подтверждённым ответам.
4. Подготовить пустой каркас по отдельному согласованному шагу; проверить его и сохранить подготовку в Git. Репозиторий уже существует, переинициализация не нужна.
5. Перейти в Plan mode, составить и согласовать план первой фичи.
6. После выхода из Plan mode выполнить implement: разработчик → автор тестов → исполнитель проверок → аудитор. До запуска убедиться в доступности ролей; наличие файлов не доказывает загрузку.
7. Посмотреть результат, при необходимости исправить, выполнить ручную приёмку и финальный коммит.

## Каркас: установка, запуск и проверки

Требуется Node.js 22.12 или новее. Установлены Vite 8.3.4, Vitest 5.0.4 и Playwright 1.64.0. Точные версии зависимостей зафиксированы в package.json и pnpm-lock.yaml.

Обычные команды при установленном pnpm:

```powershell
pnpm install --frozen-lockfile
pnpm exec playwright install chromium --no-shell
pnpm dev
```

В этой сессии pnpm доступен как встроенный инструмент Codex. Если команда pnpm не распознаётся, в PowerShell используйте:

```powershell
& 'C:/Users/olgav/.cache/codex-runtimes/codex-primary-runtime/dependencies/bin/fallback/pnpm.cmd' dev
```

Откройте http://127.0.0.1:5173. Остановка сервера — Ctrl+C. Если порт занят, сначала остановите предыдущий сервер в его терминале.

Команды проекта:

| Назначение | Команда pnpm | Прямая команда без pnpm |
|---|---|---|
| Запуск | pnpm dev | node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173 --strictPort |
| Сборка | pnpm build | node node_modules/vite/bin/vite.js build |
| Тесты логики | pnpm test:unit | node node_modules/vitest/vitest.mjs run |
| Браузерная проверка | pnpm test:e2e | node node_modules/@playwright/test/cli.js test |

Браузерная проверка сама запускает и останавливает сервер; порт 5173 должен быть свободен. Пока есть только проверка загрузки каркаса. Тестов бизнес-логики ещё нет: test:unit завершается кодом 1 с сообщением No test files found. Это не успешная проверка фичи.
